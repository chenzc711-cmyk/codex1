# 天猫店铺仓库管理系统（简洁版）

一个开箱即用的前端仓库管理系统（纯 HTML/CSS/JS），适合天猫店铺做基础库存与出入库管理。

## 功能

- 手动添加商品：商品名称、商品规格、商品成本、打包成本、在库数量。
- 批量添加商品：支持文本批量粘贴与 CSV/TXT 文件导入。
- 出入库登记：按商品记录入库/出库，自动更新在库数量。
- 出库/入库记录：按时间展示最近记录。
- 仪表盘：展示商品数量、在库总件数、库存总成本、累计入库、累计出库。
- 数据持久化：数据保存在浏览器 `localStorage`。
- 数据导出：一键导出 JSON 备份。

## 使用方式

1. 直接用浏览器打开 `index.html`。
2. 或使用本地静态服务：

```bash
python -m http.server 8000
```

然后访问：`http://localhost:8000`

## 批量导入格式

每行一条商品数据，逗号分隔：

```text
商品名称,商品规格,商品成本,打包成本,在库数量
```

示例：

```text
短袖T恤,M白色,39.9,2.5,120
防晒帽,均码米色,25,1.8,60
```
